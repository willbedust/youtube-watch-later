# YouTube Watch Later + Cleaner

Кнопка «Смотреть позже» для Chrome и Brave и отдельный CSS для очистки интерфейса YouTube.

## Установка расширения

1. Скачайте репозиторий: **Code → Download ZIP**, затем распакуйте архив.
2. Откройте `brave://extensions/` или `chrome://extensions/`.
3. Включите **Режим разработчика → Загрузить распакованное расширение**.
4. Выберите папку [`extension`](extension), содержащую `manifest.json`.
5. Отключите прежний скрипт «Смотреть позже» в Enhancer, если он установлен, и обновите YouTube.

Кнопка находится слева снизу миниатюры. В рекомендациях она добавляет видео в «Смотреть позже», а внутри списка WL — удаляет. Требуется браузер на Chromium 131 или новее.

## CSS для Enhancer for YouTube

Откройте [`enhancer-cleaner.css`](enhancer-cleaner.css), скопируйте весь код в поле пользовательского CSS в настройках Enhancer и обновите YouTube. Теги `<style>` добавлять не нужно. CSS можно использовать отдельно от расширения.

Правила скрывают игротеку, «Ещё темы», известные промобаннеры и подборки спонсорства, плашки платного продвижения и разделы меню «Навигатор» / «Другие возможности». Сетки карточек настроены на **7 элементов в ряд**. Для другого количества измените обе переменные `--ytd-rich-grid-…-per-row` и число в `repeat(7, …)`.

## Обновление

Замените файлы в папке установленного расширения, нажмите ↻ у него на странице расширений и обновите YouTube. Новую версию CSS нужно скопировать в Enhancer отдельно.

## Особенности

Расширение вызывает внутренний обработчик YouTube без открытия меню. Нет фонового процесса, внешних запросов от кода расширения, чтения cookies или телеметрии; запрос сохранения выполняет сам YouTube. Оно не загружает весь список WL и заранее не знает, какие видео уже добавлены вне расширения.

Внутренний механизм YouTube и его разметка могут меняться. При неподтверждённом результате расширение блокирует повторное действие для этого видео до перезагрузки страницы. CSS покрывает известные варианты разметки; отдельные промоблоки могут потребовать новых селекторов.

## Проверка кода

Требуется Node.js, дополнительные зависимости не нужны:

```sh
node --check extension/watch-later.js
node --test test.cjs
```

Тесты проверяют обработку ответов, ошибок, двойных кликов и смены страницы. Это локальные проверки логики, а не автоматическая проверка сохранения в аккаунте YouTube.
